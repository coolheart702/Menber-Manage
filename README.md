# 会員管理システム（印刷プレビュー・拡大縮小対応版）

Python の tkinter と SQLite3 で作った会員管理プログラムです。
会員の登録・更新・削除ができ、会員一覧を PDF にして印刷プレビュー（拡大・縮小対応）で確認・保存できます。

このページでは、**Python をまだ入れていない Windows パソコン**で、このプログラムを動かすまでの手順を説明します。

## 1. Python をインストールする

> すでに Python が入っている場合は、手順 2 へ進んでください。

### 1-1. ダウンロードとインストール

1. ブラウザで Python 公式サイトのダウンロードページを開きます。
   <https://www.python.org/downloads/windows/>
2. **「Latest Python 3 Release - Python 3.xx.x」** のリンクをクリックします。
3. 開いたページの下の方にある **「Windows installer (64-bit)」** をクリックしてダウンロードします。
4. ダウンロードした `python-3.xx.x-amd64.exe` をダブルクリックします。
5. 最初の画面の一番下にある、次のチェックボックスに **必ずチェックを入れます**。

   - ☑ **Add python.exe to PATH**

   > ⚠ これを忘れると、後の手順で `python` コマンドが使えません。
   > 忘れた場合は、インストーラーをもう一度実行して「Modify」から設定し直すか、
   > いったんアンインストールしてから入れ直してください。

6. **「Install Now」** をクリックします。
7. 「このアプリがデバイスに変更を加えることを許可しますか？」と出たら **「はい」** をクリックします。
8. 「Setup was successful」と表示されたら **「Close」** で閉じます。

### 1-2. コマンドプロンプトでインストールできたか確認

1. キーボードの **Windows キー** を押します。
2. `cmd` と入力し、表示された **「コマンド プロンプト」** をクリックします。

黒い画面（コマンドプロンプト）が開きます。以降の手順では、ここにコマンドを入力して **Enter キー** を押します。

コマンドプロンプトで次のように入力して Enter を押します。

```
python --version
```

`Python 3.13.3` のようにバージョンが表示されれば成功です。

> 「Microsoft Store」が開いてしまったり、「'python' は、内部コマンドまたは外部コマンド…として認識されていません」と表示された場合は、[うまく動かないとき](#6-うまく動かないとき) を見てください。

## 2. 必要なライブラリをインストールする

このプログラムは、Python に最初から入っている機能のほかに、次の 3 つのライブラリを使います。

| ライブラリ |  用途                                 |
| --------- | ------------------------------------ |
| reportlab | 会員一覧の PDF を作る                  |
| PyMuPDF   | PDF を画像にして印刷プレビューに表示する |
| Pillow    | プレビュー画像を画面に表示する          |

コマンドプロンプトで次のコマンドを入力して Enter を押します（1 行でまとめて入力します）。

```
python -m pip install reportlab pymupdf pillow
```

最後に `Successfully installed ...` と表示されれば完了です。
この作業は **最初の 1 回だけ** で大丈夫です。

> pythonを既にインストール済でライブラリがインストールされているか不明なときは、以下のコマンドで確認できます。
> '''
> py -m pip show reportlab PyMuPDF Pillow
> '''

## 3. このプログラムをダウンロードする

Git を使ったことがない人は、ZIP でダウンロードするのが簡単です。

1. この GitHub のページの上の方にある緑色の **「<> Code」** ボタンをクリックします。
2. **「Download ZIP」** をクリックします。
3. ダウンロードした ZIP ファイルを右クリックし、**「すべて展開」** を選んで展開します。
4. 展開したフォルダを、わかりやすい場所（例：`ドキュメント` フォルダ等）に移動します。

フォルダの中に `member_print_preview_zoom.py` があることを確認してください。

> Git を使える人は `git clone` でも構いません。

## 4. プログラムを実行する

### 4-1. エクスプローラーから実行

1. エクスプローラーで、手順 3 で展開したフォルダ(`member_print_preview_zoom.py`があるフォルダ)を開きます。
2. 開いたフォルダにある member.bat をダブルクリックします。

コマンドプロンプトも同時に開いて、「・・・は認識されていません。」というようなメッセージが表示されることがありますが、文字コードをUTF-8で保存した場合に表示されるためでプログラムの実行に影響はありません。
文字コードがShift-JISで保存されていればメッセージが表示されることはありません。

この実行方法のほか、以下の方法もあります。

### 4-2. コマンドプロンプトから実行

1. エクスプローラーで、手順 3 で展開したフォルダ(`member_print_preview_zoom.py`があるフォルダ)を開きます。
2. 上の **アドレスバー**（フォルダの場所が表示されている部分）をクリックします。
3. その **アドレスバー** の左端に `cmd` とスペースをひとつ入力して Enter を押します。

4. コマンドプロンプトが起動しますので、次のように入力して Enter を押します。

```
python member_print_preview_zoom.py
```
> python と入力してタブキーを押すと、押すたびにフォルダにあるファイル名が順に表示されます。

### 4-3「会員管理システム（印刷プレビュー・拡大縮小対応版）」のウィンドウが開きます。

手順 **4-1** 又は **4-2**のどちらか一方で、ウィンドウが開きます。

> 💡 **データベースファイルについて**
> 初めて起動すると、同じフォルダに `member.db`（会員データを保存するファイル）が自動で作られます。
> 最初は会員データが空の状態です。
> 必ず **プログラムのあるフォルダでコマンドプロンプトを開いてから** 起動してください。
> 別の場所から起動すると、その別の場所に新たに `member.db` が作られ、登録したデータが見えなくなります。

### 4-4. 2 回目以降の起動

2 回目からは、手順 **4-1** 又は **4-2** だけで起動できます。

## 5. 使い方

| ボタン | 動作                                                            |
| ----- | --------------------------------------------------------------- |
| 登録   | 入力した内容で新しい会員を登録します                              |
| 更新   | 選んだ ID の会員情報を書き換えます                                |
| 削除   | 選んだ ID の会員を削除します                                     |
| 印刷   | 会員一覧の印刷プレビューを開きます（拡大・縮小、PDF 保存ができます） |
| 終了   | プログラムを終了します                                           |

- 入力欄では **Enter キー** や **Tab キー** で次の項目へ移動できます。
- 生年月日は `YYYY-MM-DD` 形式（例：`1980-04-01`）で入力します。
- 性別は、`1`（男性）、`2`（女性）、`9`（その他）から選びます。

## 6. うまく動かないとき

### `python` と入力すると Microsoft Store が開く／「認識されていません」と出る

Python のインストール時に **「Add python.exe to PATH」** にチェックを入れ忘れている可能性があります。

- 手順 1-2 のインストーラーをもう一度実行し、**「Modify」→「Next」** と進んで
  **「Add Python to environment variables」** にチェックを入れて「Install」します。
- 設定後は、**コマンドプロンプトをいったん閉じて開き直して** ください。

それでも直らない場合は、`python` の代わりに `py` と入力してみてください。

```
py --version
py -m pip install reportlab pymupdf pillow
py member_print_preview_zoom.py
```

### `ModuleNotFoundError: No module named 'fitz'`（または `reportlab`、`PIL`）と出る

ライブラリがインストールされていません。手順 3 のコマンドをもう一度実行してください。

### `can't open file ... member_print_preview_zoom.py` と出る

コマンドプロンプトが、このプログラムのあるフォルダを開いていません。
手順 4-1 の方法で、このプログラムのあるフォルダからコマンドプロンプトを開き直してください。

### 前に登録したデータが表示されない

プログラムを別のフォルダから起動した可能性があります。
`member.db` があるフォルダ（＝このプログラムのあるフォルダ）から起動してください。
